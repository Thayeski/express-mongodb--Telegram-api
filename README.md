# Express MongoDB Telegram API

A backend service built with Express.js and MongoDB that integrates with the Telegram Bot API to send real-time notifications and automate message delivery based on application events.

This project demonstrates backend API design, database integration, and third-party API communication.

## Features

- RESTful API built with Express.js
- MongoDB integration for data storage
- Telegram Bot API integration
- Real-time message notifications
- Environment-based configuration
- Modular and maintainable project structure

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Messaging:** Telegram Bot API
- **Environment:** dotenv
